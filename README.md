# Happy Girlfriend's Day ❤️

A premium, cinematic single-page love letter website built with pure HTML, CSS, and vanilla JavaScript.

## Features
- Loading Screen with animated heart
- Hero Section with floating decorations
- Welcome Letter (luxury stationery)
- Our Story Timeline (alternating layout)
- Memory Gallery (masonry + lightbox)
- Reasons I Love You (glowing cards)
- Love Notes (interactive envelopes)
- Quotes Section (auto-rotating)
- Future Together (dream cards)
- Music Player (floating glassmorphic)
- Interactive Heart (click for burst hearts + messages)
- Final Letter + Ending

## Customization
Edit the `CONFIG` object at the top of the `<script>` in `index.html`.

## Tech
- No frameworks — pure HTML/CSS/JS
- Playfair Display + Poppins fonts
- Responsive, accessible, respects reduced-motion
